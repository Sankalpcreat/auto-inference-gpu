How the loop works

Brief

GPU facts, the model's op graph, measured numbers, dead ends, and a 28-dimension checklist.

Agent

A fresh Claude Code session profiles on the GPU, edits the engine and commits one idea.

Referee

Frozen harness on the GPU: external timing, fixed work, quality checked against saved reference outputs.

Decision

Keep only if faster than the best by more than the noise; otherwise revert and save the code on a branch.
